# ZoneEssentials 4.5.10 — SERVER / CLIENT

## English

/warp opens a scrollable destination interface, showing eight rows with wheel/scrollbar/up-down controls. Permission-filtered catalog pages contain up to 64 entries; the server revalidates permission, destination and teleport restrictions. /warp <name> and the /warps text list remain available. Existing world/data/zoneessentials.dat warps are retained. Both sides must use 4.5.10 for the new interface channel.

Minecraft 1.20.1 / Forge 47.4.10+ compatible 47.x / Java 17. Protected public Beta. Replace only the previous JAR for this side with the instance stopped; preserve world, character data and TOML. No sources, private mappings or production data. Archive/isolated tests do not certify full modpack multiplayer or render performance.

Mantiene warps de world/data/zoneessentials.dat. Ambos lados deben usar 4.5.10 por el nuevo canal de interfaz.
