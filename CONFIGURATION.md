## Applying changes / Aplicar cambios

English: Stop the server before editing TOML and back up the world plus player data. The ZoneCore reload handler validates kits, shop, auctions and jobs before applying changes; use /zonecore reload and inspect errors. Persistent homes, warps and transactions are not replaced by copying a sample TOML. ZoneProtes is optional for base rollback; without it, that integration is unavailable.

Español: Detén el servidor antes de editar TOML y respalda mundo y datos de jugadores. El manejador de recarga de ZoneCore valida kits, tienda, subastas y trabajos; usa /zonecore reload y revisa errores. Homes, warps y transacciones persistentes no se sustituyen por copiar un TOML de ejemplo. ZoneProtes es opcional para restauración de bases.
